===================================================
 PROYECTO DE AUTOMATIZACIÓN E2E (CYPRESS) Y API REST
===================================================

 AUTORA: Evelyn Lizeth Zambrano Moya
 DESCRIPCIÓN:
 Proyecto de pruebas automatizadas que incluye pruebas End-to-End (E2E) 
 para la tienda web SauceDemo y pruebas de integración/API REST para PetStore Swagger.

 REQUISITOS PREVIOS:
 - Node.js instalado (versión 16 o superior recomendada).

 INSTRUCCIONES DE INSTALACIÓN Y EJECUCIÓN:

 1. Clonar el repositorio o descomprimir el proyecto en tu computadora.
 2. Abrir una terminal en la carpeta raíz del proyecto.
 3. Instalar las dependencias ejecutando el siguiente comando:
    > npm install

 4. Ejecutar las pruebas:
    - Modo Interfaz Gráfica (Recomendado para ver la ejecución visual):
      > npx cypress open
    - Modo Consola (Headless):
      > npx cypress run
